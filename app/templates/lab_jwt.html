Lab Objective: MediCore provides a clinical API using JSON Web Tokens (JWT). The token parser suffers from the classic alg: "none" flaw. By modifying your token's payload to set "isAdmin": true and changing the algorithm header to "none", escalate your privileges to gain unauthorized access to the restricted Clinical Administration Portal.
Step 1: Sign in as Regular Patient

Obtain a validly signed HS256 JWT with "isAdmin": false.

Step 2: Exploit 'alg: none' Flaw
Privilege Escalation

Forge a modified token with "isAdmin": true and "alg": "none".

Directly generates header.payload. with no signature check enforced by the server.
